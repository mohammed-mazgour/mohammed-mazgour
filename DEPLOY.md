# Publish this site for free with GitHub Pages

This site uses the public repository `mohammed-mazgour/mohammed-mazgour`. Because the repository has the profile README name, its project site is served at `https://mohammed-mazgour.github.io/mohammed-mazgour/`.

1. Keep `index.html` at the repository root and the `projects` folder intact.
2. In the repository, open **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
3. Wait for GitHub Pages to publish the site. The free `github.io` address does not require buying a domain.

The profile README works when `README.md` is in a public repository whose name exactly matches the account username.

## Included projects

- `projects/security-checklist.html`: general security reminders; browser-only checklist state; no scanning.
- `projects/project-planner.html`: personal task board; browser-local storage; no accounts or server sync.

## Privacy and scope

The included demos use no analytics, external packages, external fonts, or tracking. The planner stores task labels in the browser's local storage. Do not enter secrets or sensitive data into it.
